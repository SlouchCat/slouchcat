# Messwerte M0 – Projektfundament

Stand: 18. Oktober 2026, Commit `8cd41aa` auf Branch `claude/m0-project-foundation`.

Hardware: Entwicklungsrechner Linux Mint 22.3 (Ubuntu noble), 28 Kerne, 31 GB RAM, NVIDIA RTX 4070
(für M0 nicht genutzt). Docker 29.9.1, Compose v5.6.0, Buildx v0.38.0. Image `slouchcat:dev`, gebaut mit
`task deploy:build` (amd64, 507 MB auf der Platte, Basis `debian:trixie-slim`, jellyfin-ffmpeg 7.1.4-3).

## Container healthy (Ziel < 5 s)

Messung mit `task deploy:healthy-time` (`deploy/scripts/measure-healthy.sh`): Start eines
Wegwerf-Containers mit leerem `/config`, Abfrage von `docker inspect .State.Health.Status` alle 100 ms.

| Lauf | Zeit bis `healthy` |
|---|---|
| 1 | 1.296 s |
| 2 | 1.179 s |
| 3 | 1.170 s |
| Median | 1.179 s |

Die Zeit enthält Container-Start, erste Migration (Sicherung entfällt, da frische Datenbank) und das
Intervall des Docker-Healthchecks (`--start-interval=1s`). Der Server selbst meldet im Log
`startup_ms` 31–33 ms.
