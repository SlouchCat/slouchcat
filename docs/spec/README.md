# Spec

`01-anforderungen-v1.md` ist die massgebliche Anforderungsspezifikation für Version 1 (Ergebnis des
Deep Interviews vom 18. Oktober 2026, 68 Abnahmekriterien mit IDs K-1 … I-7). Der Plan
(`docs/planning/03-plan-v1.md`) zitiert diese IDs; das Entscheidungsprotokoll
(`docs/planning/04-entscheidungen.md`) hält Änderungen fest. Die Spec wird nicht nachträglich
umgeschrieben; Abweichungen stehen im Entscheidungsprotokoll.
